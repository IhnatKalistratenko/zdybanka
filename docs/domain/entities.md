# Subdomain Entities

## User

Відповідає за керування користувачами системи та їхніми основними даними, необхідними для ідентифікації, автентифікації та представлення користувача в застосунку.

### User Entity

Представляє зареєстрованого користувача системи.

| Attribute       | Type    | Description                                                                           |
| --------------- | ------- | ------------------------------------------------------------------------------------- |
| `id`            | UUID    | Унікальний ідентифікатор користувача.                                                 |
| `email`         | string? | Електронна адреса користувача.                                                        |
| `username`      | string  | Унікальне ім'я користувача, яке використовується для його ідентифікації в застосунку. |
| `password_hash` | string  | Хеш пароля користувача, що використовується для автентифікації.                       |

## Event

Відповідає за створення та керування подіями, їхнім станом, часом проведення, місцем розташування та категоризацією за допомогою тегів.

### Event Entity

Представляє подію, яку користувач може створити, переглядати та до якої може приєднатися.

| Attribute          | Type        | Description                                    |
| ------------------ | ----------- | ---------------------------------------------- |
| `id`               | UUID        | Унікальний ідентифікатор події.                |
| `name`             | string      | Назва події.                                   |
| `description`      | string?     | Опис події.                                    |
| `address`          | string?     | Текстова адреса місця проведення події.        |
| `status`           | EventStatus | Поточний статус події.                         |
| `creator_id`       | UUID        | Ідентифікатор користувача, який створив подію. |
| `created_at`       | DateTime    | Дата та час створення події.                   |
| `start_time`       | DateTime    | Дата та час початку події.                     |
| `end_time`         | DateTime    | Дата та час завершення події.                  |
| `max_participants` | int         | Максимальна кількість учасників події.         |
| `coordinates`      | Point       | Географічні координати місця проведення події. |

### Tag Entity

Представляє тег, який використовується для категоризації та фільтрації подій.

| Attribute | Type   | Description                    |
| --------- | ------ | ------------------------------ |
| `id`      | UUID   | Унікальний ідентифікатор тегу. |
| `name`    | string | Назва тегу.                    |

## Chat

Відповідає за спілкування користувачів у межах подій та зберігання повідомлень.

### Chat Entity

Представляє текстовий чат, пов'язаний з конкретною подією.

| Attribute     | Type       | Description                                |
| ------------- | ---------- | ------------------------------------------ |
| `id`          | UUID       | Унікальний ідентифікатор чату.             |
| `event_id`    | UUID       | Ідентифікатор події, до якої належить чат. |
| `name`        | string     | Назва чату.                                |
| `description` | string     | Опис чату.                                 |
| `status`      | ChatStatus | Поточний статус чату.                      |

### Message Entity

Представляє текстове повідомлення, надіслане користувачем у чаті.

| Attribute   | Type          | Description                                              |
| ----------- | ------------- | -------------------------------------------------------- |
| `id`        | UUID          | Унікальний ідентифікатор повідомлення.                   |
| `chat_id`   | UUID          | Ідентифікатор чату, у якому було надіслано повідомлення. |
| `sender_id` | UUID          | Ідентифікатор користувача, який надіслав повідомлення.   |
| `content`   | string        | Текстовий вміст повідомлення.                            |
| `sent_at`   | DateTime      | Дата та час надсилання повідомлення.                     |
| `status`    | MessageStatus | Поточний статус повідомлення.                            |
